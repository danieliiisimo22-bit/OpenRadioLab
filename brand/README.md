# OpenRadioLab brand assets

The supplied OpenRadioLab brand kit provides the logos, banners, social images and design tokens in this directory. These are identity graphics, not screenshots or device-test evidence. No font files are included.

- `banners/`: English and Spanish README headers; PNG versions preserve the supplied typography.
- `logo/`: vector and raster logos for light, dark and monochrome use.
- `social/`: social preview images in English and Spanish.
- `guides/`: usage guidance and the brand board.
- `design-tokens.json`: colors, typography and spacing.

The application's appearance and icons are unchanged by this documentation update. Real photos and a programming video will be added separately.
