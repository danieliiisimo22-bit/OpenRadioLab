# OpenRadioLab · Brand Guide (EN)

**Brand promise:** Modern radio programming, built for reliability and openness.

## Identity
- **Name:** OpenRadioLab (one word; capital O, R and L).
- **Voice:** precise, calm, informative; evidence before claims.
- **Visual direction:** restrained engineering software. No fake interfaces, stock radios, gradients or neon effects.
- **Symbol:** an open circular path surrounding paired signal arcs and a central point. Designed as a compact software icon.

## Colors
| Role | HEX | Use |
|---|---|---|
| Deep Ink | `#172E3B` | Brand backgrounds, headings |
| Signal Teal | `#217C84` | Logo mark, emphasis, links |
| Marine | `#214A58` | Secondary UI and headings |
| Soft Mist | `#F6F8F7` | Light canvases |
| Slate | `#526670` | Supporting text |
| Soft Line | `#D6E2E1` | Borders and dividers |
| White | `#FFFFFF` | Clear space and reverse contrast |

## Typography
- **Inter** (open-source SIL OFL; obtain separately from its official distribution; not included in this kit).
- Titles: Inter Bold / 700. Body: Inter Regular / 400. UI labels: Inter SemiBold / 600.
- Fallback: Arial, system sans-serif. Keep copy short and left aligned.

## Logo rules
- Clear space: at least half the symbol width around the logo.
- Minimum wordmark width: 220 px. Small-scale usage: icon-only logo.
- Never recolor with rainbow gradients, outline all letters, stretch, rotate, or change proportions.
- `primary` on light, `reversed` on dark, `mono` for one-color reproduction.

## Screenshots
- Use only real OpenRadioLab captures with non-sensitive test configurations.
- Recommended: app main window, channel editor, read/write confirmation, independent KPG-158D verification.
- Avoid implying that untested radios are compatible. Vendor name only for factual compatibility; no affiliation implied.
