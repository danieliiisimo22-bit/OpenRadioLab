# OpenRadioLab · Guía de marca (ES)

**Mensaje principal:** Modern radio programming, built for reliability and openness.

**Adaptación al español:** Programación moderna de radios, construida para la confiabilidad y la apertura.

## Identidad
- **Nombre:** OpenRadioLab (una palabra; mayúsculas O, R y L).
- **Personalidad:** precisa, sobria, técnica y transparente. La evidencia tiene prioridad sobre las promesas.
- **Estética:** software profesional de ingeniería; sin interfaces inventadas, imágenes de radios genéricos, degradados brillantes ni neón.
- **Símbolo:** aro abierto que encierra dos ondas y un punto central; preparado para icono de aplicación.

## Tipografía
- **Inter**, con licencia abierta SIL OFL. Debe instalarse por separado; el kit no distribuye fuentes.
- Títulos: Inter Bold 700; párrafos: Regular 400; etiquetas: SemiBold 600.
- Alternativa: Arial o sans-serif del sistema.

## Uso del logo
- Área despejada: mínimo 1/2 del ancho del símbolo por lado.
- Anchura mínima de logotipo completo: 220 px; por debajo, usar solo el icono.
- Nunca distorsionar, rotar, deformar ni aplicar efectos luminosos.
- `primary` sobre claro, `reversed` sobre oscuro, `mono` para un color.

## Evidencia visual
- Capturar la interfaz real con una configuración de prueba sin datos privados.
- Capturas sugeridas: pantalla principal, edición, lectura/escritura y verificación posterior en KPG-158D.
- No insinuar soporte universal: por ahora solo hay un perfil TK-2402K; Windows x86-64 validado.
