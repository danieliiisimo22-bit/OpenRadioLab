Suggested repository description:

> Read, edit and program your radio. A native, open-source radio lab built with Rust and Slint. Currently Windows + Kenwood TK-2402K.

Spanish alternative:

Suggested topics: `radio-programming`, `two-way-radio`, `rust`, `slint`, `kenwood`, `tk-2402`, `serial-port`, `desktop-app`, `open-source`.

The About description and topics are repository settings; committing this file does not update them. An owner can set them using the gear beside About on the repository home page. If GitHub CLI is installed and authenticated:

```sh
gh repo edit danieliiisimo22-bit/OpenRadioLab --description "Read, edit and program your radio. A native, open-source radio lab built with Rust and Slint. Currently Windows + Kenwood TK-2402K." --add-topic radio-programming,two-way-radio,rust,slint,kenwood,tk-2402,serial-port,desktop-app,open-source
```

For the social preview, upload [the English image](../brand/social/social-preview-en.png) or [the Spanish image](../brand/social/social-preview-es.png) in the repository settings under Social preview. Committing these images alone does not select a preview.
